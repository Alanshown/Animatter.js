# @animatter/react

Optional React lifecycle hooks for the shared Animatter runtime. Peer dependencies: React >=18 and animatter ^0.1.0. Version 0.1.0 is available on npm.

useAnimatter returns {ref,world}; useSurface registers a ref and cleans up on unmount. Keep surface option objects stable. World options are captured on mount; configure the world for live changes.

[Usage and tests](https://github.com/Alanshown/Animatter.js/blob/main/README.md#framework-integrations). MIT.
